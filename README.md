# Obstacle Dodger 🐊

A simple text-based obstacle avoidance game written in pure Python.

You must guide the player across a 4×4 grid, avoid the crocodiles, and reach the goal in two levels.

## How to Play

- Use the following keys to move:
  - `w` → Up
  - `s` → Down
  - `a` → Left
  - `d` → Right

- Avoid the crocodiles
- Reach the goal to complete each level

## How to Run

```bash
python main.py
